# UMKM Go

UMKM Go adalah platform digital yang membantu pengguna menemukan dan mendukung UMKM di sekitar mereka dengan lebih mudah. Pengguna dapat menjelajahi berbagai UMKM, melihat produk yang tersedia, mengetahui lokasi usaha, serta melakukan pembelian melalui satu platform.

## Fitur

* Pencarian UMKM berdasarkan nama atau kategori
* Katalog produk UMKM
* Peta interaktif untuk melihat lokasi UMKM
* Pembelian produk melalui website
* QR Code sebagai bukti pembelian
* Validasi pembelian melalui pemindaian QR Code
* Status pembelian menjadi redeemed setelah produk diambil
* Tampilan responsif untuk berbagai perangkat

## Tujuan

UMKM Go dibuat untuk mempermudah masyarakat dalam menemukan UMKM lokal sekaligus membantu UMKM memperluas jangkauan dan meningkatkan kemudahan dalam proses transaksi.

## Teknologi

* HTML
* CSS
* JavaScript
* Interactive Map
* QR Code

## Cara Menjalankan

1. Clone repository ini.
2. Buka folder project.
3. Buka file `index.html` menggunakan browser.

Website juga dapat diakses melalui GitHub Pages.
